# Grupo-M

Proyecto de la asignatura de Desarrollo de Aplicaciones Web.

Nuestro proyecto trata de una aplicación web para un taller. En esta aplicación gestionamos las ordenes de reparación, dando a los clientes la opción de citarse para traer sus vehículos teniendo un día y hora asignados. También gestionará las reparaciones incluyendo las piezas que se usen, el tiempo de la reparación y que mecanico ha estado trabajando en la reparación. Por último, la aplicación generará la factura con el precio de la reparación.
